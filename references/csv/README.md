# CSV 知识条目说明

## 格式规范

所有 CSV 必须满足：
- UTF-8 编码，BOM 可选
- 第一行为列标题
- id 列唯一且不为空
- content 列不为空
- 不得包含空列

## 校验

```bash
python scripts/validate_csv.py
```
