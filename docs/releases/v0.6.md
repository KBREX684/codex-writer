# Codex Writer v0.6 发布说明

v0.6 是从早期可运行版本进入上线前补齐的版本，继续参照 `webnovel-writer` 的工作区、题材模板、长期记忆和 dashboard 思路，但实现保持 Codex Writer 的本地 CLI、投影读模型和可测试工程结构。

## 新增能力

- 工作区恢复：新增 `use`、`where`、`resume`，可绑定当前写作项目并给出下一章建议命令。
- 中文题材模板：新增 `genres list/show`，内置玄幻、都市脑洞、规则怪谈、狗血言情、古言、现实题材 6 个模板。
- 章节规划增强：`plan` 会根据项目 `genre` 自动吸收匹配题材模板，写入章节任务书的风格约束和审查提醒。
- 记忆管理增强：`memory` 新增 `dump`、`conflicts`、`update`，支持导出 scratchpad、检测语义事实冲突、更新记忆条目状态。
- Dashboard 增强：JSON/HTML/text 输出新增事件链、开放伏笔、实体关系投影概览。

## 工程边界

- v0.6 不引入重型向量库或远端服务；RAG 仍保持当前本地 BM25 / references 优先策略。
- 子 Agent 路由仍由 `.codex-writer/agents/子Agent路由.json` 管理，题材模板只提供路由提示，不绕过现有审查和提交链。
- Dashboard 仍是只读观察面，不写入项目状态。

## 验收重点

- `python -m pytest` 必须全量通过。
- `.codex-plugin/plugin.json`、`pyproject.toml`、`codex_writer.__version__` 必须统一为 `0.6.0`。
- 插件命令面必须包含 `genres`、`use`、`where`、`resume`。
