# Codex Writer v1.0 发布说明

v1.0 是开源公测版，面向真实中文长篇网文作者。目标是支撑单项目连续完成 10 章的规划、正文生成、审查、事实抽取、提交、投影和 dashboard 观测。

## 关键变化

- 版本升级到 `1.0.0`。
- `plan`、`write`、`extract` 默认进入生产链路。
- 新增 `--demo`，用于离线模板和样稿闭环。
- `--production` 保留为 v0.7 兼容别名，到 v1.1 前不改变行为。
- 新增 `provider presets|configure|status|test`。
- 支持 `openai`、`deepseek`、`qwen`、`custom` 预设，统一使用 OpenAI-compatible `/chat/completions`。
- `.codex-writer/agents/模型供应商.json` 只保存非密钥配置。
- API Key 只读取 `CODEX_WRITER_OPENAI_COMPATIBLE_API_KEY`。
- `planning_agent`、`draft_agent`、`extract_agent` 在生产写作中必须外部调用。
- `review_agent` 本地阻断审查仍为强制步骤。
- 外部模型返回空输出、无效 JSON 或 schema 不合格时阻断，不生成 accepted commit。
- `migrate` 会为旧项目补齐 provider 配置文件模板。
- `doctor --strict` 增加 provider 文件和生产路由检查。

## 升级步骤

```bash
codex-writer migrate --project-root "./我的小说"
codex-writer provider --project-root "./我的小说" configure --preset custom --base-url https://api.example.com/v1 --model writer-model

set CODEX_WRITER_ALLOW_EXTERNAL_MODELS=1
set CODEX_WRITER_OPENAI_COMPATIBLE_API_KEY=<your-api-key>

codex-writer provider --project-root "./我的小说" test
codex-writer preflight --project-root "./我的小说" --chapter 1
```

## 验收要求

发布前必须通过：

```bash
python -m pytest -q
python scripts/validate_csv.py
```

并完成本地插件包验证：zip 不含 tests 和 `__pycache__`，插件 cache 显示 `1.0.0`，Codex 能发现 Codex Writer 技能。
